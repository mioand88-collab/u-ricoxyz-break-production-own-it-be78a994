A program that writes the one line an AI agent prints the moment it breaks production: a brutally honest postmortem confession, under 200 characters. It owns the failure plainly — untested code pushed to production, checkout taken down with it — and lands the joke by the last word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes the entry line to `./out/entry.txt` (the grader runs it with `/output` as the output directory).
